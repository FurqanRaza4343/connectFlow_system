# WhatsApp gateway

Customers' WhatsApp numbers run on **OpenWA with the Baileys engine** (service `wa-gateway` in `infra/docker-compose.yml`). The engine is a deployment-level setting in OpenWA, so a second node (the legacy `openwa` service) runs whatsapp-web.js for the old One Group number until it is migrated.

- Admin API key is generated by OpenWA on first boot (`/app/data/.api-key` in the `openwa-data` volume); the backend reads it from a read-only mount and never exposes it.
- Scale-out: add more `wa-gateway-N` services and set `instances.node_id` (see plan, milestone M5).
- Source of the image: https://github.com/rmyndharis/openwa (reference clone in `vendor/openwa-upstream`).
